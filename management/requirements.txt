# JA4PROXY-2026-0044:
# Every dependency is pinned with '==' (exact version). Floating '=='
# pins let pip resolve to a new upstream release silently on image
# rebuild, which is the classic dependency-confusion / malicious-upgrade
# risk. Pin at known-good minima preserved from the previous '==' file
# so this commit is behavioural-compat for existing deployments.
#
# The roadmap target (see docs/security/FINDINGS_REGISTER.md 0044) is
# pip-compile + hash-checking (`pip install --require-hashes`). Until
# that lockfile lands, '==' exact pins close the primary exposure.
#
# Bumping a version? Change the '==' line, rebuild, run the management
# test suite, and open a separate PR. Do NOT revert to '=='.
