- **`build-first-party-images` no longer skips its builds under `$CI` (Phase 847c follow-up)**: the target built the five `make build`-produced images only on local runs, a guard written for the one CI caller at the time (the `Security Scan` job, which pre-builds via `make build`). 847c's two new callers — the scheduled baseline monitor and the `scan-regression` PR gate when a first-party surface is in scope — run no `make build`, so every first-party image was scanned-as-absent (`trivy FATAL: unable to find the specified image`, exit 2; first seen on monitor run 39459929246). Fail-closed, so no false clean bill of health, but the monitor could never scan and the required gate reddened any PR touching a first-party Dockerfile. The guard now keys on presence in the job (`docker image inspect`) instead of on `$CI`: the `Security Scan` job still pays nothing, and any other caller gets the images it needs.
