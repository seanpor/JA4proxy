- **Redis ACL authentication fix (Phase 813, production-impacting)**: fixed a chain of bugs that meant the Go proxy, `redis_exporter`, and `docker-compose.prod.yml`'s proxy service could never actually authenticate to Redis — `--requirepass-file` is not a real Redis directive, `config/redis_acl.conf` (now `config/redis_acl.conf.template`) was bind-mounted with unrendered `${VAR}` placeholders, and the proxy itself authenticated as the deliberately-disabled `default` ACL user. A new `deploy/docker/redis-entrypoint.sh` renders the ACL template from Docker secrets at container start; `config/proxy.yml`'s existing (but never-enabled) `acl_users.enabled` flag is now `true`. See `docs/phases/PHASE_813.md`.
