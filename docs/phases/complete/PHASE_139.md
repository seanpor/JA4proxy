# Phase 139: Open-Source Governance & OpenSSF Best Practices

> **Status:** PROPOSED
> **Size:** SMALL
> **Depends on:** Phase 135
> **Owner:** Gemini CLI

## Goal
Transition the project from a private security tool to a mature, open-source-ready ecosystem by implementing formal governance and achieving the OpenSSF Best Practices badge.

## Scope
- **Contribution Model**: Create `CONTRIBUTING.md`, `GOVERNANCE.md`, and a Code of Conduct.
- **Vulnerability Disclosure**: Formalize the `SECURITY.md` with a Coordinated Vulnerability Disclosure (CVD) policy and specific SLAs.
- **OpenSSF Best Practices Badge**: Complete the manual questionnaire at `bestpractices.coreinfrastructure.org` to achieve the "Passing" level.
- **Documentation**: Modernize the `README.md` contribution section to reflect the new governance.

## Acceptance Criteria
- [ ] `passing` badge acquired and displayed in `README.md`.
- [ ] Formal governance docs merged to the root of the repository.
- [ ] CVD policy published with clear reporter communication guidelines.
